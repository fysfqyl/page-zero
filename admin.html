口令是一个 GitHub 令牌

这个后台直接读写 GitHub 仓库 fysfqyl/page-zero：写文章就是提交一次 commit，提交完 GitHub Pages 会自动重新构建。没有服务器，也没有密码，令牌只存在这台设备的浏览器里。

请用 fine-grained 令牌，只授权 page-zero 这一个仓库、Contents 设为 Read and write，并设置过期时间。公共电脑上不要勾选“记住”。

返回首页

怎么创建这个令牌
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 选 Only select repositories，只勾 page-zero。
  3. Permissions → Repository permissions → Contents 设为 Read and write；如果列表里有 Pages，也设为 Read and write（可选）。
  4. Expiration 选 90 天，Generate，把 github_pat_ 开头的那串复制下来，粘到上面。
  5. 令牌只显示一次；丢了就重新生成一个。
